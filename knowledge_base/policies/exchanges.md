# Exchanges

## Size or color exchanges

You can exchange an item for a different **size or color of the same product**
within **30 days of delivery**. The item must meet the same conditions as a return:
unused outdoors, clean, with tags and all parts.

Exchange shipping is **free once per order**, both ways. Further exchanges on the
same order are charged the $7.95 return shipping fee.

### How to exchange

1. Go to **Orders**, choose the item, and select **Exchange**.
2. Pick the new size or color.
3. Send back the original using the prepaid label.

We ship the replacement as soon as the carrier scans your return package, so you
don't have to wait for it to reach our warehouse.

## Exchanging for a different product

We can't swap one product for a different one directly. Instead, return the
original item for a refund and place a new order. This keeps pricing accurate if
the new item costs more or less.

## Out of stock

If the size or color you want is out of stock, we'll refund the item instead and
email you to let you know.
